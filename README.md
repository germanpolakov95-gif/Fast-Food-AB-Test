# A/B-Test Analysis of Fast Food Marketing Campaigns
A/B testing for marketing campaigns

## Overview
This repository contains a simple A/B-test analysis of a fast-food marketing campaign dataset from Kaggle: [Fast Food Marketing Campaign A/B Test](https://www.kaggle.com/datasets/chebotinaa/fast-food-marketing-campaign-ab-test). The goal is to evaluate the effectiveness of three different promotions on sales in thousands of dollars, considering factors like market size and store age.

The analysis is performed using libraries: pandas, numpy, scipy, matplotlib, and seaborn. It includes data loading, descriptive statistics, visualization, ANOVA test


## About the repository
 - AB-test.ipynb (file with code)
 - analysis-report.pdf (Detailed analysis report with visualizations)
 - WA_Marketing-Campaign.csv (source dataset)


## Brief conclusions of the analysis

- There are significant differences in sales across promotions, with Promotion 1 and 3 outperforming Promotion 2
- Promotion 3 is most effective in large markets, while Promotion 1 works well across all sizes
- Store age has negligible correlation with sales, suggesting other factors drive performance
